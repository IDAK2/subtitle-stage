# README Design Contract

## readmeArchetype
Rehearsal prompt book.

## readmeNarrativeVoice
Precise stage manager calling cues.

## readmeSectionPattern
Callboard, house notes, cue book, jury booth, rehearsal call, strike notes.

## readmeMotif
Annotated theatrical prompt book.

## requiredFactsPlacement
Callboard carries live coordinates. House notes defines the product. Cue book maps contract state and methods. Jury booth explains consensus and guards. Rehearsal call gives setup and tests. Strike notes records architecture, deployment, and limits.

## bannedReadmePatterns
No tasting card, accession dossier, generic overview, feature bullets, or verification matrix.

## proofOfDifference
The document uses cue-call notation, margin directions, and a stage sequence rather than museum or tasting language.
